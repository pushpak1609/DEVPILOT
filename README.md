# DevPilot

AI-powered code assistant that lets you chat with any GitHub repository. DevPilot indexes your codebase, retrieves the most relevant code chunks for your question (RAG), and streams grounded answers back with file citations.

## Features

- 🔗 **GitHub OAuth login** — connect your repos securely
- 🧠 **RAG-grounded chat** — answers are backed by actual code from your repository, with file/line citations
- ⚡ **Real-time streaming** — token-by-token responses over SSE
- 🗂️ **Session management** — rename, delete, and auto-titled chat sessions (title is generated by the LLM after your first exchange)
- 📊 **Repository indexing** — chunking + embeddings pipeline with live indexing status
- 🎨 **Clean, dark-mode UI** — built with Next.js, Tailwind, and shadcn-style components

## Tech Stack

**Backend**
- Java 21, Spring Boot 4.1.1, Spring AI
- PostgreSQL + [pgvector](https://github.com/pgvector/pgvector) for vector similarity search
- [Groq](https://groq.com/) (OpenAI-compatible API) for chat streaming
- [Google Gemini](https://ai.google.dev/) for embeddings
- GitHub OAuth2 for authentication

**Frontend**
- Next.js (App Router) + React
- TypeScript, Tailwind CSS
- TanStack Query for server state
- Server-Sent Events (SSE) for streaming chat

**Infra**
- Docker Compose for local Postgres + pgvector

## Architecture

```
User → Next.js frontend → Spring Boot backend
                              │
                              ├─ GitHub API (fetch repo files)
                              ├─ Gemini (generate embeddings)
                              ├─ pgvector (store/retrieve code chunks)
                              └─ Groq (stream chat completions)
```

**Chat flow:** `ChatController` → `ChatService.streamReply()` → `CodeContextRetriever` (RAG via pgvector) → `ChatPromptBuilder` → `ChatStreamHandler` (SSE via `SseEmitter`)

## Getting Started

### Prerequisites

- Java 21+
- Node.js 18+
- Docker (for Postgres + pgvector)
- A [Groq API key](https://console.groq.com/keys)
- A [Google AI Studio API key](https://aistudio.google.com/apikey) (for embeddings)
- A [GitHub OAuth App](https://github.com/settings/developers)

### 1. Clone the repo

```bash
git clone https://github.com/pushpak1609/DEVPILOT.git
cd DEVPILOT
```

### 2. Start Postgres (pgvector)

```bash
docker compose up -d
```

### 3. Configure the backend

Copy the example config and fill in your real values:

```bash
cd backend/src/main/resources
cp application-example.properties application.properties
```

Edit `application.properties` with your:
- Groq API key
- Gemini API key
- GitHub OAuth client ID/secret
- A random token encryptor password + salt

### 4. Run the backend

```bash
cd backend
./mvnw spring-boot:run
```

Backend runs on `http://localhost:8080`.

### 5. Run the frontend

```bash
cd client
npm install
npm run dev
```

Frontend runs on `http://localhost:3000`.

### 6. Open the app

Visit `http://localhost:3000`, log in with GitHub, connect a repository, wait for indexing to finish, and start chatting.

## Security Notes

- `application.properties` is gitignored — never commit real API keys or secrets. Use `application-example.properties` as a template.
- OAuth tokens are encrypted at rest using a configurable encryptor password/salt — set your own values in production, don't use the defaults.
